# SDD Workspace

This folder stores durable context for Codex SDD runs in this repository.

- `state/`: project-wide context that should survive sessions.
- `specs/`: per-feature specs, plans, reviews, verification, and retros.
- `milestones/`: long-running roadmap slices.
- `templates/`: copyable artifact templates.
- `scripts/`: helpers for creating workflow folders.

Primary workflow: gstack decides, GSD stabilizes, Superpowers executes.
